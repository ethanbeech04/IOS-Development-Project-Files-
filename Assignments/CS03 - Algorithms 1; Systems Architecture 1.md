## Objectives

### Algorithms 1:
- I can define an algorithm
- I can explain why searching and sorting are classic problems in computer science
- I can write a `while` loop and explain when it stops
- I can use a range and `enumerated()` in a `for`-in loop
- I can create a `Set` and use `insert`, `contains` and `remove`
### Systems Architecture 1:
- I can describe what an operating system does: it manages hardware, memory, files and running programs
- I can describe the layers between my Swift code and the hardware (app, frameworks, OS, hardware)
- I can describe what the Swift compiler does: it turns my code into machine code the CPU can run
- I can explain the difference between a program and a process
- I can explain what the iOS sandbox is and what an app can and can't reach

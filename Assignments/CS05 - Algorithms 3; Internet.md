## Objectives

### Algorithms 3:
- I can explain how binary search works and why the array has to be sorted
- I can explain what O(log n) means
- I can rank O(1), O(log n), O(n) and O(n²) from slowest-growing to fastest-growing
- I can explain why dictionary and `Set` lookup is faster than searching an array
- I can pick the faster of two solutions to the same problem using Big-O
### Internet:
- I can describe the client-server model: my app sends a request, and a server sends a response
- I can explain what an IP address is and what DNS does
- I can describe how data travels across the internet in packets
- I can name the parts of an HTTP request and response (method, URL, status code, body)
- I can explain what an API is and how an app uses one to get data
- I can explain what HTTPS adds to HTTP

## Assigned Reading

Before our next lesson, spend about 30 minutes with the readings below. Tomorrow we write functions that call themselves and compare the classic sorts. We also start the SOLID principles.

**1. Recursion** (~5 min)

- https://www.programiz.com/swift-programming/recursion

Look for the stopping condition in each example. Tomorrow we call it the base case.

**2. Bubble sort, selection sort and merge sort** (~15 min)

- https://github.com/kodecocodes/swift-algorithm-club/blob/master/Bubble%20Sort/README.markdown

- https://github.com/kodecocodes/swift-algorithm-club/blob/master/Selection%20Sort/README.markdown

- https://github.com/kodecocodes/swift-algorithm-club/blob/master/Merge%20Sort/README.markdown

You don't need to read any of the code. Bubble sort: read through "Example," skip "Memory," and stop at "Code." Selection sort: read through "An example," then skip to "Performance." Merge sort: read through "Merging" and stop at "Top-down implementation."

**3. SOLID and the Single Responsibility Principle** (~10 min)

- https://www.freecodecamp.org/news/solid-principles-explained-in-plain-english/

Read from the top through "Common Pitfalls and Anti-patterns" and stop at "Open-Closed Principle." The code is Java, which reads a lot like Swift.
